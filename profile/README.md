# Sourcetree - Git Repository and Branch Management Tool

> Visualize repository history, inspect code changes, and manage branches through a graphical Git workspace.

Sourcetree is a desktop Git client developed by Atlassian for navigating source control tasks through a visual interface. Its repository views help developers examine commit history, track working changes, and understand relationships between branches.

Use Sourcetree to clone repositories, stage selected changes, compare file revisions, create commits, manage stashes, and work with merges. Integrated Git workflow tools provide a visual alternative to performing common repository operations entirely through commands.

## Git Repository Features

| Feature | Description |
|---|---|
| Repository Cloning | Create local copies of remote repositories. |
| Commit Graph | Visualize commit history and branch relationships. |
| Working Copy Review | Inspect modified, added, and removed files. |
| Selective Staging | Stage changes by file, section, or individual line. |
| Branch Management | Create, switch, compare, and merge branches. |
| Visual Diff | Examine differences between file revisions. |
| Stash Management | Store unfinished changes and restore them later. |
| Interactive Rebase | Reorganize commits using supported history editing tools. |
| Cherry-Pick | Apply selected commits to another branch. |
| Git-Flow Support | Work with structured branching workflows. |
| Git LFS | Work with repositories that track large files through Git LFS. |
| Submodule Support | Navigate repositories that include linked submodules. |
| Commit Search | Search repository history for relevant commits and changes. |
| Remote Synchronization | Fetch, pull, and push repository updates. |

## Exploring Repository History

![Sourcetree Commit Graph Interface](https://wac-cdn.atlassian.com/dam/jcr:580c367b-c240-453d-aa18-c7ced44324f9/hero-mac-screenshot.png?cdnVersion=3035)

The commit graph presents repository history as a visual sequence of changes. Select a commit to inspect its details, follow branch development, and understand how separate lines of work connect.

This view is particularly useful when reviewing parallel development or identifying the commit associated with a particular change.

## Reviewing Changes Before Committing

Sourcetree lets you inspect modified files and review their differences before creating a commit. Stage an entire file or select specific sections to control which changes become part of the next changeset.

Keeping unrelated modifications separate makes commit history easier to review and maintain.

## Keeping Branches Ready for Integration

1. Open the repository and inspect the current working copy.
2. Review pending changes and stage the relevant sections.
3. Create a commit with a descriptive message.
4. Compare the active branch with its intended integration branch.
5. Inspect incoming changes before merging or rebasing.
6. Synchronize the repository with its remote when appropriate.

Sourcetree brings these operations into a visual workspace, helping developers review repository state before changing its history or integrating new work.
